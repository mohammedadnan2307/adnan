# Hello, I'm Adnan

Welcome to my personal corner of the internet. This website serves as my digital portfolio — a place where I can showcase the projects I've built, the technologies I enjoy, and a little bit about who I am outside of work.

### What's Inside?

Currently, the site hosts a few standalone web applications and personal pages:

* **[About Me (`/about`)](https://mohammedadnan2307.github.io/adnan/about/index.html)**: A glimpse into my background as a software developer, as well as my hobbies (chess, dance, and a built-in music player featuring some of my favorite tracks!).
* **[Polynomial Equation Solver (`/polynomial-solver`)](https://mohammedadnan2307.github.io/adnan/polynomial-solver/index.html)**: A fully functional mathematical tool I built to calculate roots, find turning points, generate equations, and plot interactive graphs of polynomial functions. 

### Why I built this
I enjoy working on projects and developing tools in the hope that they will translate back to the real world and have a direct, positive impact on people's lives. This portfolio is a living breathing document of that journey.
